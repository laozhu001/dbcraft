# DB Craft Demo GIF And Script Order

## Recommended Short Demo GIF

Target length:

- `12s` to `18s`

Recommended order:

1. Open `sample` model
2. Show the visual schema workspace
3. Open `AI Build`
4. Return and click `Sync`
5. Show SQL preview

## Why This Order

- It explains the product in one loop:
  - start from a real model
  - show visual design
  - show acceleration with AI
  - end with SQL output

This is the clearest conversion path for a marketplace listing.

## Short Demo Script

## Scene 1: Workspace Overview

Time:

- `0s` to `4s`

What to show:

- DB Craft top bar
- sample model on canvas
- visible table relationships

Goal:

- establish that this is a visual schema design tool

## Scene 2: AI Build

Time:

- `4s` to `8s`

What to show:

- open `AI Build`
- model preset selector visible
- a short requirement already filled in

Goal:

- show that schema creation can start from natural language

## Scene 3: Sync To SQL

Time:

- `8s` to `13s`

What to show:

- close dialog
- click `Sync`
- SQL preview opens

Goal:

- show the handoff from visual model to exportable SQL

## Scene 4: End Frame

Time:

- `13s` to `16s`

What to show:

- hold on SQL preview or briefly return to the workspace

Goal:

- leave the user with a clear output-focused ending

## Recommended Cover Frame

Use:

- the opening workspace frame

Reason:

- it is more visually distinctive than a dialog box

## Recommended Long Demo Video

Target length:

- `30s` to `60s`

Recommended order:

1. Open DB Craft
2. Open the `sample` model
3. Show the current project and model file
4. Briefly pan the schema canvas
5. Open `AI Build`
6. Show `Send to Codex`
7. Run `Sync`
8. Show SQL preview
9. Briefly show help or multilingual support

## Long Demo Script

## Part 1: Open And Orient

- Open DB Craft with the sample workspace
- Let the viewer see:
  - current project
  - current model file
  - schema canvas

## Part 2: Show Fast Modeling Entry

- Open `AI Build`
- Keep the preset selector visible
- Show one realistic requirement sentence

## Part 3: Show Collaboration Fallback

- Open `Send to Codex`
- Hold for a moment on the handoff options

## Part 4: Show Output

- Click `Sync`
- Hold on SQL preview long enough for viewers to understand the result

## Part 5: Show Product Polish

- Open help or switch language
- Keep this short

## Marketplace Priority

If you only create one demo asset, prioritize:

- `workspace -> AI Build -> Sync -> SQL preview`

If you create a second demo asset, prioritize:

- `workspace -> Send to Codex -> handoff flow`

## Capture Notes

- Use the English UI for the default public demo
- Use `D:\DBdesigner\samples\sample.dbmodel.json`
- Keep browser zoom at `100%`
- Avoid showing personal paths if you can crop them out cleanly
- Do not expose real API keys
