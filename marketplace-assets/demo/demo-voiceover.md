## Long Voiceover

## 45-Second Version

Use for:

- marketplace demo video
- narrated walkthrough
- product intro page

Suggested voiceover:

“DB Craft is a local visual schema studio built for moving from requirements to SQL faster.  
In this sample workspace, you can see the current project, the active model file, and the full relational diagram on one screen.  
Instead of writing schema notes by hand, you can shape tables visually, manage relationships, and keep the model saved in the current workspace.  
If you want a faster starting point, AI Build lets you describe the business need in natural language and turn it into table drafts.  
When the design is ready, Sync writes the model and SQL back to the workspace and opens a SQL preview immediately.  
And if you want to continue through a collaborative workflow, Send to Codex prepares a handoff file for the next step.  
DB Craft keeps the path from model to SQL simple, visual, and easy to review.”
