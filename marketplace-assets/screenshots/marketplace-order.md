# DB Craft Marketplace Screenshot Order

## Recommended Default Order

1. `01-main-workspace.png`
2. `02-ai-build.png`
3. `03-sync-sql-preview.png`
4. `04-send-to-codex.png`
5. `05-help-or-multilanguage.png`

## Why This Order

## 1. Main Workspace First

- This is the fastest way to tell users what DB Craft is.
- It shows the core value immediately:
  - visual schema design
  - project-aware modeling
  - real table relationships

## 2. AI Build Second

- This is the strongest acceleration story after the core workspace.
- It tells users they can go from requirement text to table draft quickly.

## 3. Sync + SQL Preview Third

- This closes the main product loop:
  - model
  - validate
  - export SQL
- It helps technical users trust that DB Craft produces implementation-ready artifacts.

## 4. Send to Codex Fourth

- This is a differentiator, but not the primary product identity.
- It works best as an advanced or bonus capability after users already understand the main flow.

## 5. Help / Multilanguage Fifth

- This is a polish and trust screenshot.
- It is useful, but not stronger than the first four for initial conversion.
